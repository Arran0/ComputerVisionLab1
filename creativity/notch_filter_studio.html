What this demonstrates

A periodic interference pattern is, by definition, concentrated at a few discrete frequencies. In the spatial domain it is spread over every pixel and is almost impossible to remove without destroying the image; in the frequency domain it collapses to a small number of isolated bright peaks that can simply be set to zero. This is precisely the argument of §2.5 of the lab manual, and this tool makes the whole loop — forward transform, surgical edit, inverse transform — directly manipulable.

  • Forward transform. A hand-written radix-2 Cooley–Tukey FFT is applied separably, rows then columns, giving the complex matrix F. The power spectrum S = |F|² is real.
  • Display. fftshift moves DC to the centre, and the S.^0.1 compression from §2.5(b) is applied so that components many orders of magnitude below DC remain visible.
  • Notching. Clicking maps the shifted display coordinate back to the unshifted index, u = (cx + N/2) mod N. Because the input is real, F is conjugate-symmetric, so every notch is mirrored to (N-u, N-v) — zeroing only one of the pair would leave an imaginary residue in the output.
  • Ideal vs Gaussian. A hard-zero notch is a rectangle in frequency, whose transform is a sinc, so it rings. The Gaussian profile trades a little residual interference for a visibly cleaner result — the same ringing-vs-suppression trade-off met in §2.5(e).
  • Peak detection reproduces the argument used to locate the peaks in pck-int.jpg without ginput: take local maxima of |F| outside a DC exclusion disc and keep the strongest.

The fence source is the harder case of §2.5(f): a square-wave-like occluder is not a single sinusoid but a fundamental plus its harmonics, so a single notch pair is never enough and a perfectly clean recovery is not achievable — exactly the honest outcome the manual anticipates.
