# Input images

Place the course image files from NTULearn
(Course Contents → Laboratory Material → Images) in this folder.

Required by the lab manual:

| File | Used by | Manual says |
|---|---|---|
| `mrt-train.jpg` | §2.1, §2.2 | 320×443×3 uint8 colour image, poor contrast |
| `lib-gn.jpg` | §2.3, §2.4 | additive **Gaussian** noise |
| `lib-sp.jpg` | §2.3, §2.4 | additive **speckle** noise |
| `pck-int.jpg` | §2.5 | dominant diagonal interference lines |
| `primate-caged.jpg` | §2.5(f) | primate behind a fence |
| `book.jpg` | §2.6 | slanted view of an A4 book, 210 mm × 297 mm |

Any additional images the course provides can be dropped here too; the
scripts only read the names listed above.
